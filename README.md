# sungjunlee/homebrew-tap

Third-party Homebrew tap for [aibris](https://github.com/sungjunlee/aibris).

```bash
brew install sungjunlee/tap/aibris
```

This is not `homebrew/core`. The fully-qualified command trusts that formula
(Homebrew item trust), not the whole tap. Formula `sha256` values come from
the same GitHub Release publisher as `checksums.txt`.

`Formula/aibris.rb` is updated by GoReleaser on each `v*` tag of
`sungjunlee/aibris`.
